# Проєкт: Бібліотечний каталог (Library Catalogue)

## 1. Функціональні та нефункціональні вимоги
### Функціональні вимоги (Functional Requirements):
- **Перегляд каталогу:** Користувач може переглядати список книг у вигляді карток (обкладинка, назва, автор, жанр).
- **Пошук книг:** Реалізовано рядок живого пошуку за назвою книги або автором.
- **Фільтрація:** Користувач може фільтрувати книги за жанрами (Всі, Фантастика, Наука, Історія).
- **Інтерактивність:** Кнопка «Детальніше» відкриває модальне вікно з деталями та можливістю замовлення.

### Нефункціональні вимоги (Non-Functional Requirements):
- Використання семантичних тегів HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Стилі винесені в окремий зовнішній CSS-файл (`style.css`), дизайн адаптивний (Flexbox/Grid).
- JavaScript реалізований через роботу з подіями DOM-дерева (`script.js`).

---

## 2. Дизайн сторінки (Page Schema)
- **Шапка (Header):** Логотип сайту та інтерактивне поле пошуку.
- **Панель фільтрів:** Кнопки для швидкого сортування контенту за категоріями.
- **Основна сітка (Main Grid):** Картки книг із зображеннями-іконками, назвами, авторами та кнопками взаємодії.
- **Підвал (Footer):** Інформація про копірайт.
- **Модальне вікно:** Спливаюче вікно для детального перегляду вибраної книги.
